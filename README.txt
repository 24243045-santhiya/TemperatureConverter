TEMPERATURE CONVERTER - JAVA SWING

Requirements:
- JDK 21 (or another compatible JDK)
- Visual Studio Code (optional)
- Extension Pack for Java in VS Code (optional)

Run in VS Code:
1. Extract this ZIP file.
2. Open the extracted TemperatureApp folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:
   javac TemperatureConverter.java
   java TemperatureConverter

Features:
- Celsius, Fahrenheit, and Kelvin conversions
- Input validation
- Rejects temperatures below absolute zero
- Desktop GUI built with Java Swing
